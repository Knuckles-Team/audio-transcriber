| `CONN-AUDIO-TRANSCRIBER-SDK-CENTRALIZATION-R001.1` | **TLS profile for secure streams.** A `wss://` connection to the PersonaPlex server must take its SSL context from `resolve_tls_profile` for the `personaplex` prefix (`SCION-CENTRALIZED-CAPABILITIES-R008`). The client must not build an SSL context or disable verification. A `ws://` connection uses no TLS. Proving test: `tests/test_sdk_transport.py::test_secure_stream_uses_the_tls_profile`. Caller chain: The `audio-transcriber` console script runs `audio_transcriber/audio_transcriber.py::audio_transcriber` with `--interact --server wss://...`, which calls `AudioTranscriber.interact` (line 528) and then `audio_transcriber/personaplex_client.py::PersonaPlexClient.connect` (line 20), which calls `resolve_tls_profile("personaplex")`. Shape: `PersonaPlexClient.connect` passes `self._tls_profile.ssl_context` from `scion_sdk.tls.resolve.resolve_tls_profile` to `websockets.connect` for `wss://` and calls it with no `ssl` argument for `ws://`; no SSL context is built locally. | A `wss://` connect passes the profile context, and a `ws://` connect passes none. |
| `CONN-AUDIO-TRANSCRIBER-SDK-CENTRALIZATION-R001.2` | **Stream dependency from the SDK.** The `mcp` extra must take the websockets driver from the SDK `stream` extra and must not pin `websockets` itself (`SCION-CENTRALIZED-CAPABILITIES-R040`). The SDK floor must be `0.3.11` or later. Proving test: `tests/test_sdk_transport.py::test_websockets_comes_from_the_sdk_stream_extra`. Caller chain: Installing the package resolves the `dependencies` list in pyproject.toml; the `websockets` driver imported by `audio_transcriber/personaplex_client.py` is then supplied by the `stream` extra of `scion-sdk[mcp,stream]` that the `audio-transcriber` console script path uses. Shape: pyproject.toml `dependencies` lists `scion-sdk[mcp,stream]>=0.6.4,<0.7.0` and has no `websockets` pin; the metadata check is a text read of pyproject.toml as done in `tests/test_sdk_transport.py`. | `pyproject.toml` pins no `websockets` and requests `scion-sdk[mcp,stream]`. |
